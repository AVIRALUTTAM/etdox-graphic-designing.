# Aviral Uttam — Graphic Design & Ad Tech Portfolio (2026)

A high-performance, cinematic, and interactive portfolio showcasing 6 core graphic design and creative technology disciplines for **Aviral Uttam**.

## 🌟 Disciplines & Highlights

1. **Interactive Generative Hero Canvas**
   - Photoshop & Figma transformation bounding marquee with live dimension tags.
   - Real-time celestial canvas particle orb with cursor-tracking and click physics.
   - Generative AI prompt bar with laser scanline sweep.

2. **Discipline 01: Logofolio**
   - 12 Curated identity marks with sector filtering (Healthcare, Tech, Luxury, Hospitality, Lifestyle).
   - In-depth inspection modal with vector geometry, concept rationale, and color swatches.

3. **Discipline 02: Branding Design (Ourvita Case Study)**
   - 5-tab interactive case study: Strategy & Overview, Wordmark Anatomy, Interactive Type Tester (*Labora Regular*), One-Click Color Studio with live canvas tinting, and full stationery/packaging collateral.

4. **Discipline 03: Social Media Post Campaigns**
   - Dual grid switcher for E-commerce/Interactive Kiosk and Tech Launches/Festive campaigns.

5. **Discipline 04: Packaging Design**
   - Interactive collection switcher: Gourmet Organics & FMCG vs. Retail Confectionery & Hardware.

6. **Discipline 05: Print Media Design**
   - Livspace Editorial Brochure with 6-spread page catalog inspection modal.
   - Highway Unipole Billboard with toggleable night floodlights and atmospheric cone beams.

7. **Discipline 06: UI/UX Design**
   - Poppy movie streaming iOS app.
   - Epic Games Store desktop redesign with interactive Before vs. After comparison slider.
   - Full subpages ecosystem architecture.

8. **Direct Brief Transmission**
   - Direct integration delivering submitted project briefs to `aviraluttam@gmail.com`.

---

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla CSS3 (Custom Dark Luxury Studio tokens), Modern ES6+ JavaScript.
- **Bundler**: Vite.
- **Audio Engine**: Synthesized Web Audio API tactile sound effects.
- **Canvas Physics**: 2D HTML5 Canvas particle swarm engine.

## 🚀 Running Locally
