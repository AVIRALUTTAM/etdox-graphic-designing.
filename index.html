Client: Poppy

Premium Movie & TV Streaming App

Poppy is a subscription-based movie and TV streaming app designed to deliver a seamless viewing experience across mobile, tablet, and smart TV platforms. The app aims to provide personalized recommendations, curated collections, and high-quality streaming with an intuitive user interface.

Key features
  • Style: Minimalist, cinematic, bold visuals, immersive dark UI.
  • Target Audience: Age 16–45, globally distributed.
  • Home screen with personalized recommendations and trending content.
  • Search & filter with genres, actors, and more.
  • Watchlist and continue watching sections.
  • Video player with subtitles, quality settings, and playback controls.
  • Content detail pages with trailers, cast info, and reviews.
  • Subscription management and in-app purchases.

Web

Design

Client: Epic Game Store ( Redesign )

Digital video games platform

Epic Games Store (EGS) is a leading digital storefront for PC gaming. The goal of this redesign is to enhance user experience, improve discoverability, and create a modern, engaging, and intuitive platform for users. The redesign will focus on a more streamlined user interface, better categorization, an updated visual style, and enhanced performance.

Key features
  • Improve User Experience (UX): Ensure smooth, intuitive navigation across the site.
  • Target Audience: PC gamers of all ages, with a focus on both casual and hardcore gamers.
  • Modernize Visual Aesthetic: Refresh the visual design while maintaining the Epic Games brand identity.
  • Optimize for Discoverability: Separate every Pages Games Store, Community, Game Pass, Accessories etc.
  • Performance Optimization: Speed up load times and overall performance.
  • Integration of New Features: Implement features such as wishlist management, personalized game recommendations, downloads section and improved user profiles.
